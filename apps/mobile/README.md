# Pixel8 mobile controller

Flutter owner app for Android and iOS. See [`docs/mobile.md`](../../docs/mobile.md) for local API configuration, authentication, media upload behavior, and screen pairing.

Run from this directory with `flutter pub get` and `flutter run`. Local Android emulators use `--dart-define=PIXEL8_API=http://10.0.2.2:3001` to reach the API on the host machine.
